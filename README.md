# Поиск максимального значения в большом массиве данных

Программа генерирует слайс из 100 миллионов случайных целых положительных чисел
и ищет в нём максимум двумя способами, сравнивая время работы:

1. **В один поток** — функция `maximum` проходит по всему слайсу.
2. **В 8 горутинах** — функция `maxChunks` делит слайс на `CHUNKS` частей,
   ищет максимум каждой части в отдельной горутине (синхронизация через
   `sync.WaitGroup`), а затем выбирает наибольший из найденных.

## Запуск

```bash
go run .
```

Пример вывода:

```
Генерируем 100000000 целых чисел
Ищем максимальное значение в один поток
Максимальное значение элемента: 2147483613
Время поиска: 163878 мкс
Ищем максимальное значение в 8 потоков
Максимальное значение элемента: 2147483613
Время поиска: 85179 мкс
```

Время зависит от процессора. Для работы нужно около 800 МБ оперативной памяти.

## Тесты

```bash
go test -v ./...
go test -race ./...   # дополнительно проверяет отсутствие гонок данных
```

## Обработка крайних случаев

- `generateRandomElements` при размере `0` или меньше возвращает пустой слайс.
- `maximum` и `maxChunks` для пустого слайса возвращают `0`: все числа
  положительные, поэтому `0` не совпадёт с настоящим максимумом.
- Если элементов меньше, чем частей, `maxChunks` не запускает горутины
  и вызывает `maximum` напрямую.
- Если длина слайса не делится на `CHUNKS` без остатка, последняя часть
  забирает остаток, и элементы в конце слайса не теряются.
- Каждая горутина записывает результат только в свою ячейку слайса максимумов,
  поэтому мьютекс не нужен.
